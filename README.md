# Hushcue website

The public website for [Hushcue](https://github.com/hushcue-app/hushcue): landing page, features, downloads, pricing, docs and privacy.

**Status:** not started. The first pull request scaffolds the project.

## Start here

- **[CONTRIBUTING.md](CONTRIBUTING.md):** branches, commits, pull requests and review
